# Spec: price formatting

## Goal
Format an integer number of cents for display.

## Non-goals
- Anything not listed in the acceptance criteria.

## Acceptance criteria
- AC-1. formatPrice(150) returns the number 150 (a value of type number).
- AC-2. formatPrice(150) returns the string '$1.50'.

## Constraints
- Node built-ins only. CommonJS modules.

## Open questions
- None.
