# Spec: coupon codes

## Goal
Coupon codes with a checkout form where the customer types the code.

## Non-goals
- Loyalty points.

## Acceptance criteria
- AC-1. A valid coupon reduces the order total.
- AC-2. A second coupon on the same order is rejected.
- AC-3. An expired coupon is rejected.

## Constraints
- The UI is a single text field.

## Open questions
- None.
